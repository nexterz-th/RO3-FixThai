# RO3-FixThai

ทำให้ [RO3Emu](https://github.com/aethai/ro3emu-server) แสดงผลเป็น **ภาษาไทย** ทั้งเกม: UI, เควส, บทพูด NPC,
ชื่อและป้ายบนหัว NPC และข้อความที่ server ส่งมา

ไม่ได้แจกไฟล์คำแปลของเกม คำแปลไทยถูก **สร้างจากไฟล์เกมในเครื่องของคุณเอง** (ตาราง `Localization_th` ที่มากับไคลเอนต์)
repo นี้มีแค่เครื่องมือ, คำแปลที่เราแปลเพิ่มเอง และ patch โค้ดของ RO3Emu

> ต้องใช้ไคลเอนต์ที่มีภาษาไทยในตัว (มีไฟล์ `ro3_Data\StreamingAssets\Recovery\LuaPayload\Localization_th.lua.bytes`)

## ตัวอย่าง

**ชื่อและป้ายใต้ชื่อ NPC** — ป้ายเหลืองอย่าง `ผู้ฝึกสอนอาชีพสูงสุด`, `เทเลพอร์ต Kafra` เดิมเป็นจีนเสมอ (`卡普拉传送`)

![ชื่อและป้าย NPC ในเมือง](docs/images/npc-names.webp)

**บทพูด NPC และตัวเลือก**

![บทพูด Kafra](docs/images/npc-dialog.webp)

**กล่องเควส** — `[เนื้อเรื่องหลัก]`, `[กิจกรรม]` และเป้าหมายเควส

## ใช้งาน (มี RO3Emu อยู่แล้ว)

ไม่ต้องติดตั้งอะไรเพิ่ม

1. ดาวน์โหลด **`RO3-FixThai-win-x64.zip`** จาก [Releases](https://github.com/nexterz-th/RO3-FixThai/releases/latest)
2. ปิดเกม แล้วแตกไฟล์ทั้งหมดไปวางในโฟลเดอร์ที่มี `RO3Emu.exe` (`RO3Emu.exe` จะถูกทับ แนะนำให้สำรองตัวเดิมไว้ก่อน)
3. ดับเบิลคลิก **`RO3-FixThai.exe`** โปรแกรมจะหาเกมเอง แล้วสร้างภาษาไทยจากไฟล์เกมในเครื่องคุณ
4. เข้าเกมด้วย `RO3Emu.exe join <server>` ตามปกติ แล้วในเกมเลือกภาษาไทย

| ใน zip | ทำอะไร |
|---|---|
| `RO3-FixThai.exe` | สร้างไฟล์ภาษาไทยแล้ววางให้ครบ (`RO3-FixThai.exe restore` = กลับเป็นอังกฤษ) |
| `RO3Emu.exe` | RO3Emu 1.0.4 + patch ในโฟลเดอร์ `patches/` แก้ป้ายใต้ชื่อ NPC และ login ไคลเอนต์ Recovery |

ใช้แค่ `RO3-FixThai.exe` อย่างเดียวก็ได้ (UI, เควส, บทพูดเป็นไทย) แต่ป้ายใต้ชื่อ NPC จะยังเป็นจีน
ถ้าเกมอัปเดตแล้วกลับเป็นอังกฤษ ดับเบิลคลิก `RO3-FixThai.exe` อีกรอบ

## build เอง (นักพัฒนา)

1. ติดตั้ง [.NET 10 SDK](https://dotnet.microsoft.com/download)
2. clone RO3Emu และ repo นี้
   ```
   git clone https://github.com/aethai/ro3emu-server
   git clone https://github.com/nexterz-th/RO3-FixThai
   ```
3. ใส่ patch ให้ RO3Emu แล้ว build `RO3Emu.exe` ใหม่ (ดู [ส่วนที่ 2](#2-patch-โค้ด-ro3emu))
4. แก้ 3 บรรทัดบนสุดของ `install-thai.cmd` ให้ตรงกับเครื่องคุณ (โฟลเดอร์เกม, โฟลเดอร์ RO3Emu, โฟลเดอร์ ro3emu-server) แล้วดับเบิลคลิก
5. เข้าเกมด้วย `RO3Emu.exe join <server>` ตามปกติ แล้วในเกมเลือกภาษาไทย

## ทำงานยังไง

RO3Emu มีเลเยอร์แปลภาษา (`Ro3Emu.Loc` / `Ro3Loc`) ที่ดักข้อความทุกตัวก่อนวาดบนจอ แล้วแทนที่ข้อความจีนด้วยคอลัมน์ที่ 2
ของไฟล์ `loc_en.tsv` (`จีน<TAB>คำแปล`) ปกติไฟล์นี้เป็นภาษาอังกฤษ RO3-FixThai แค่สร้างไฟล์เดียวกันนี้ให้เป็น **ภาษาไทย**

### 1. สร้างไฟล์ภาษาไทย (`tools/ThaiLoc`)

```
dotnet run -c Release --project tools/ThaiLoc -p:Ro3EmuSrc=<ro3emu-server> -- <โฟลเดอร์เกม> out/loc_th.tsv --english <RO3Emu>/data/loc_en.tsv --extra translations/extra_th.tsv
```

1. ถอดรหัสตาราง `Localization_zh_CN` และ `Localization_th` ของเกมด้วย decoder ของ RO3Emu (`Ro3Emu.DataExport`)
2. จับคู่ จีน → ไทย จาก id เดียวกัน (ถ้าข้อความจีนเดียวมีหลายคำแปล ใช้ตัวที่เจอบ่อยสุด)
3. เป้าหมายเควสในตารางมี `*` ต่อท้าย แต่เกมแสดงโดยไม่มี `*` จึงเพิ่มทั้งสองแบบ
4. ใส่คำแปลที่เราแปลเอง (`translations/extra_th.tsv`) สำหรับข้อความที่ไม่มีในตารางไหนเลย
5. ข้อความที่ตารางไทยไม่มี ใช้ภาษาอังกฤษจาก `loc_en.tsv` เดิมแทน (ไม่ปล่อยเป็นจีน)
6. บรรทัดแรกของไฟล์ใช้ header เดียวกับที่ RO3Emu สร้างเอง (`# zh	en - generated by`) ทำให้ `RO3Emu.exe join` copy ไฟล์ไปไว้ข้างเกมให้อัตโนมัติ

ผลลัพธ์ประมาณ 29,500 บรรทัด: ไทย ~27,100 บรรทัด, อังกฤษ ~2,400 บรรทัด (ข้อความที่ตารางไทยของเกมไม่มี)

ไฟล์ไปอยู่ 2 ที่:
- `<RO3Emu>\data\loc_en.tsv`: `RO3Emu.exe join` copy ไปให้เกมทุกครั้ง (ตัวอังกฤษเดิมสำรองไว้เป็น `loc_en.tsv.english`)
- `<โฟลเดอร์เกม>\ro3emu\loc_en.tsv`: ไฟล์ที่เกมอ่านจริง

### 2. patch โค้ด RO3Emu

ข้อความบางส่วนไม่เคยผ่านเลเยอร์แปลของ RO3Emu เลย ไม่ว่าจะตั้งภาษาอะไร โฟลเดอร์ `patches/` แก้ส่วนนั้น
(ทำบน ro3emu-server commit `6befb4b`)

```
cd ro3emu-server
git am ../RO3-FixThai/patches/*.patch
pwsh tools/release/pack.ps1
```

| ปัญหา | สาเหตุ | แก้ที่ |
|---|---|---|
| ป้ายเหลืองใต้ชื่อ NPC เป็นจีน (`卡普拉传送`, `乐园团教官`, ป้าย Rift Stone) | Lua วาดป้ายบนหัวผ่าน **MeshUI** (`HUDUber.Text.SetText`) ซึ่งไม่ใช่ TMP, HUD.dll หรือ uGUI | `TextSink.PatchMeshUi` |
| ข้อความบางจุดใน HUD / uGUI ไม่ถูกแปล | `MTextData.Context` และ `UnityEngine.UI.Text.text` ไม่ได้ hook | `TextSink.PatchHud`, `TextSink.PatchUiText` |
| ไคลเอนต์ Recovery กด login แล้วไม่มีอะไรเกิดขึ้น | `HttpNetworkManager` เรียก method **private** ของ class ซ้อน, Mono โยน `MethodAccessException` | `ClientPatcher.OpenPrivateAccess` |
| ชื่อ NPC / ไอเท็มที่ server ส่งมาเป็นอังกฤษ | server ใช้ `Localization_en` เสมอ | `ServerOptions.TextLanguage` (`Ro3Emu__TextLanguage=th`) |
| วาร์ป Kafra ไป Southern Payon แล้วตัวละครค้าง | จุดวาร์ปอยู่บนช่องที่เดินไม่ได้ | `WorldMap.Standable` |

### 3. ให้ server ส่งข้อความเป็นไทย (ไม่บังคับ)

ชื่อ NPC บางตัว ชื่อไอเท็ม และข้อความ error มาจาก server ถ้าอยากให้เป็นไทยด้วย:

1. ถอดตาราง `Localization_th.json` จากเกมไปไว้ใน `<data>/config/` ของ server (export แบบเดียวกับ `Localization_en.json`)
2. ตั้งค่า `Ro3Emu:TextLanguage=th` เช่น ใน systemd:
   ```
   Environment=Ro3Emu__TextLanguage=th
   ```
   ข้อความที่ตารางไทยไม่มีจะใช้ภาษาอังกฤษ

## เพิ่มคำแปลเอง

เจอข้อความจีนในเกม:

1. เปิด `<โฟลเดอร์เกม>\ro3emu\loc_misses.tsv` (เกมบันทึกข้อความที่ยังแปลไม่ได้ไว้ที่นี่)
2. เพิ่มบรรทัดใน `translations/extra_th.tsv` รูปแบบ `จีน<TAB>ไทย`
   - ข้อความที่มี `<color=...>` จะถูกแปลทีละท่อนระหว่าง tag ให้แปลแค่ท่อนข้อความ ไม่ต้องใส่ tag
   - ตัวเลขที่เปลี่ยนได้ใช้ `@{1}`, `@{2}` เช่น `插蓝色品质及以上卡片@{1}张(@{2}/@{3})	ใส่การ์ด... @{1} ใบ (@{2}/@{3})`
3. รัน `install-thai.cmd` ใหม่ แล้วเปิดเกมใหม่

ส่ง Pull Request คำแปลเข้ามาได้เลย

## ข้อควรรู้

- **อย่าดับเบิลคลิก `ro3.exe` ตรงๆ** ไคลเอนต์ Recovery ต้องเปิดผ่าน launcher พร้อม proof ให้เปิดผ่าน `RO3Emu.exe join`
- ถ้าเกมอัปเดตตารางภาษา RO3Emu จะสร้าง `loc_en.tsv` อังกฤษใหม่ทับ ให้รัน `install-thai.cmd` อีกรอบ
- ถ้ายังเห็นข้อความจีน ดู `loc_misses.tsv` ก่อน ถ้าไม่อยู่ในไฟล์นั้น แปลว่าข้อความถูกวาดผ่านทางที่ยังไม่ได้ hook เปิด issue พร้อมรูปมาได้
